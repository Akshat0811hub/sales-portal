# OrbitSales CRM Turbo Sync Extension (v4.0)

## Installation (30 Seconds)
1. Open Google Chrome or Microsoft Edge and navigate to `chrome://extensions`.
2. Enable **Developer mode** (top-right toggle).
3. Click **Load unpacked** and select this `chrome-extension` folder.
4. Click the **OrbitSales Turbo Sync** icon in your browser toolbar and select the salesperson assigned to that laptop (`Jinendra`, `Vishal`, `Rahul`, or `Archana`).

## Key Capabilities
- **60ms Millisecond DOM Mutation Sync**: Captures every sent and received WhatsApp Web message and Gmail email immediately.
- **100% Zero-Loss Post-Install Capture**: Skips ancient pre-install chats while capturing every single new message without keyword filtering.
- **Accurate Attribution**: Distinguishes messages sent by the Salesperson (`[Sales - Name]`) vs received from the Client (`[Client - Name]`).
